# Color Alchemy — releases

Color Alchemy is a color-mixing puzzle game for Android: match a target color by mixing the colors you have, in a limited number of moves. 20 levels, English and Turkish.

This repository only hosts the installable builds. The source code is private.

## Download

**[Latest APK](https://github.com/omerfkurt55/color_alchemy_release/releases/latest/download/color-alchemy.apk)** · [all releases](https://github.com/omerfkurt55/color_alchemy_release/releases)

Installing: open the APK on your Android phone and allow "install unknown apps" for your browser or file manager when asked. Updates install over the previous version and keep your progress.
